# Xcode 27 test-warning allowlist

The 2.0 test lane treats compiler warnings from DaVinci sources as actionable. The
following messages are emitted by Apple frameworks while `ImageRenderer` or
CoreSimulator drives UIKit-backed controls; they are not compiler diagnostics and
must not be silenced globally:

| Pattern | Source of the message | Handling |
|---|---|---|
| `Unable to render flattened version of ... PlatformTextFieldAdaptor` | `DSTextField` snapshots use SwiftUI's UIKit-backed `TextField`. | Keep the snapshot because it still validates the surrounding layout; validate text-field behavior and accessibility separately. |
| `Unable to render flattened version of ... CircularUIKitProgressView` | `DSActivityIndicator`/indeterminate `DSProgressBar` snapshots. | Keep the semantic/behavior tests and snapshot the stable surrounding view. |
| `Unable to render flattened version of ListRepresentable` or `NavigationStackRepresentable` | Gallery smoke tests exercise navigation containers through `ImageRenderer`. | Gallery navigation is covered by construction tests; only pure SwiftUI screens use bitmap rendering. |
| `Accessing FocusState's value outside of the body of a View` | SwiftUI's `ImageRenderer` does not install the focus coordinator used by `DSTextField`. | Do not use this message as evidence of a production focus regression; use hosted UI tests for focus behavior. |
| `Accessing Environment<Bool>` or `Accessing Environment<DSTheme>` outside of a View | `DSTextField` and its field-message/accessibility modifiers are evaluated by `ImageRenderer` without a hosted environment. | Snapshot assertions still inject the theme and enabled state; use hosted UI tests for environment propagation. |
| `fopen failed for data file: errno = 2` | CoreSimulator/ImageIO probes generated in-memory payloads used by image-loader tests. | Image tests intentionally use generated bytes and assert the loader error; there are no missing repository fixtures. |
| `Metadata extraction skipped, no AppIntents.framework dependency found` | Xcode's metadata processor for package targets. | Toolchain noise; no App Intents are declared by DaVinci. |
| `IOSurfaceClientSetSurfaceNotify failed` / `XPCErrors` from `PointerUI` | Simulator services during headless rendering. | Record as simulator diagnostics only; the test result remains authoritative. |

The allowlist is deliberately pattern-based and narrow. A new compiler warning, a
new warning category, or a warning mentioning a DaVinci source must be investigated
before updating this file.
